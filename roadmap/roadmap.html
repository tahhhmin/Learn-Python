AI/ML Roadmap

    From zero Python to AI/ML

    A build-first plan: about 8-10 hours a week, roughly 48 weeks. Each phase has steps, a "move on when you can" checklist and projects. Tick things off as you go; your progress is saved in this browser.

    The learning loop
    1. Learn one small concept (15-25 minutes).
    2. Write a tiny example, then change it until you know what each part does.
    3. Build a feature with it without copying a full solution.
    4. Test edge cases, debug, and note what went wrong.
    5. Commit to GitHub with a short README.
    6. At the end of a phase, rebuild a smaller version from memory.
    Ground rules
    1. Mostly build: roughly 25% learning, 65% coding, 10% review early on, then 30% concepts, 60% experiments, 10% write-up in the ML phases.
    2. Type every line yourself. Stuck? Try 20 minutes, search the error, then ask.
    3. Weeks are estimates, not deadlines. If a checkpoint feels shaky, take another week.
    4. Choose one main course per phase and use others only to fill gaps.
    5. Aim for 8-12 polished projects, not 20 half-finished ones. Projects marked ★ are the core set.

    Make every project portfolio-worthy

    1. Problem: one paragraph on who it helps and what it does.
    2. Scope: list the first three features and add nothing else until they work.
    3. Build in slices: one feature, test it, then the next.
    4. Test: normal, edge and invalid inputs.
    5. README: setup steps, usage, screenshots or sample output, limitations and lessons learned.
    6. Polish last: clear file names, functions, useful comments and a clean Git history.

    When you are stuck

    • Read the error from the bottom up; the last line usually names the problem.
    • Delete code until the bug disappears, then add it back piece by piece.
    • Explain the problem aloud, or write it as a forum question. Include your code and the exact error.
    • Take a 15-minute break.

    Common traps

    • Tutorial hell: watching without attempting the next step yourself.
    • Jumping to neural networks before Python, pandas and evaluation feel easy.
    • Copy-pasting code you cannot explain line by line.
    • Skipping math, or trying to master all of it first. Learn it in small pieces next to code.
    • Chasing certificates and leaderboard rank over understanding and reproducibility.
    • Comparing your week 3 to someone else's year 3.

    Where this leads

    At university, your programming, data structures, discrete math, statistics and later ML courses will build on this. Arriving able to code, with a public GitHub portfolio, helps with internships, research roles and scholarships. Keep adding to your projects as you learn. Stretch ideas: a Telegram bot, a cricket match predictor, a movie recommender, a study planner app.
